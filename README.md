# ⚽ PelApp — Protótipo Interativo

> *"O jogo não espera."*

Protótipo funcional desenvolvido para a disciplina de **Interação Humano-Computador** da **Universidade Federal de Ouro Preto (UFOP)**. 

O **PelApp** é uma plataforma voltada para facilitar a organização de partidas esportivas amadoras, confirmação de presença com garantia de quórum e reserva de quadras e arenas.

🔗 **Acesse o protótipo online:** [PelApp — GitHub Pages](https://sxbrinz.github.io/PelApp---Prototype/)

---

## 🎯 Sobre o Projeto

A partir de entrevistas e questionários aplicados com estudantes universitários, identificamos que a organização de jogos amadores costuma depender de grupos informais, gerando problemas recorrentes como desistências de última hora, informações desencontradas de horário/local e desequilíbrio entre o nível dos jogadores. 

O **PelApp** nasceu para resolver essas dores por meio de uma interface prática que centraliza toda a jornada esportiva: o usuário pode explorar partidas e arenas livremente como visitante ou fazer login para criar jogos em etapas, definir regras de aprovação, gerenciar listas de suplentes com ofertas temporizadas (15 minutos), reservar quadras via lista ou mapa interativo com filtros específicos, simular pagamentos via PIX e coordenar detalhes finais no chat integrado da partida. 

Por se tratar de um protótipo de validação de UX/UI, todos os dados são persistidos localmente no navegador (`localStorage`) sem sincronização entre dispositivos, e os fluxos de pagamento (PIX e Cartão) e notificações são estritamente demonstrativos.

* **HTML5, CSS3 e JavaScript / React** (build compilado para hospedagem estática)
